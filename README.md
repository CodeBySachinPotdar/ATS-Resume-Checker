> **ResumeMatch AI** is a production-grade web application engineered to evaluate how well a candidate's resume matches a target job description and provide actionable, anti-fraud-compliant recommendations to maximize pass rates through Applicant Tracking Systems (ATS).

---

## ⚡ Quick 5-Minute Tour

1. **Upload or Paste**: Submit your resume in PDF, DOCX, or TXT format (or paste raw text).
2. **Paste Job Posting**: Supply the target job description.
3. **Deterministic & Semantic ATS Scoring**: Get an estimated compatibility score calculated across **8 weighted categories**:
   - Keyword Match (25%)
   - Required Skills (20%)
   - Experience Alignment (15%)
   - Job Title Alignment (10%)
   - Semantic Similarity (10%)
   - Resume Structure (10%)
   - Achievement Quality (5%)
   - Formatting Compatibility (5%)
4. **Side-by-Side Comparison**: Visually inspect Green (Matched), Yellow (Related concepts), and Red (Missing keywords).
5. **AI Bullet Refinement**: Transform weak statements into high-impact Google-style achievement bullets (`Original` → `Problem` → `Improved` → `Why it is better`).
6. **Export ATS-Friendly Resume**: Download certified single-column PDF, Word DOCX, or TXT resumes in 4 templates.

> **Important Product Principle**: The ATS score is an **estimated compatibility indicator**, not a score generated by a specific company's ATS. The system enforces strict **anti-fraud guidelines**: candidates are never advised to fabricate skills or metrics they do not possess.

## 🚀 Quick Start (Local Run in 60 Seconds)

### Option A: Docker Compose (All-in-One)
Start PostgreSQL, Redis, Apache Kafka, Spring Boot backend, and React frontend with a single command:

```bash
docker compose up --build
```

- **Frontend Web UI**: [http://localhost:3000](http://localhost:3000)
- **Backend API**: [http://localhost:8080](http://localhost:8080)
- **OpenAPI / Swagger UI**: [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)

---

### Option B: Standalone Developer Mode (Zero Docker Prerequisites)

The backend includes embedded H2 fallback, in-process async event dispatching, and a zero-cost Mock AI provider, enabling you to run everything locally without external infrastructure:

#### 1. Start Spring Boot Backend:
```bash
cd backend
mvn spring-boot:run
```
*Backend runs on port `8080`.*

#### 2. Start React Frontend:
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on [http://localhost:5173](http://localhost:5173).*

## 🛠️ Tech Stack Overview

| Tier | Technologies |
|---|---|
| **Frontend** | React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Recharts, React Router |
| **Backend** | Java 21, Spring Boot 3.4.3, Spring Web, Spring Security, Spring Data JPA |
| **Persistence** | PostgreSQL 16 (production), H2 (local embedded development), Redis 7 |
| **Event Broker** | Apache Kafka 3.8 (KRaft mode) with in-process `@Async` fallback |
| **Document Processing**| Apache PDFBox 3.0, Apache POI 5.4, Java Standard I/O |
| **AI Layer** | Pluggable `AIProvider` (MockAIProvider, OpenAI GPT-4o-mini, Google Gemini) |
| **API Documentation** | Springdoc OpenAPI 3 / Swagger UI |
